# Forever Market Tracker

A private, personal planner for **WoW Forever**. It runs on my own home network, for my own characters only.
It is not a public website, an addon, or a service.

## What it does

- Reads my own auction house scans (Auctionator, TSM and a small personal addon) to track prices and market depth.
- Plans gear upgrades by level and zone, including quest rewards and dungeon loot I can get before I reach a zone.
- Plans profession leveling and gold making from current market prices.

## Data and credits

- Item, quest, vendor and source data from [ForeverDB.net](https://foreverdb.net).
  The planner shows this credit, with a visible link to https://foreverdb.net, on every page.
- Classic quest data: [QuestieDB](https://github.com/Questie/QuestieDB).
- Dungeon loot and quests: the Lootwise and DungeonJournal (by Exehn) addons, read from my own installed copies.
- WoW Forever client data: [wago.tools](https://wago.tools).

## Use of the ForeverDB API

Personal and non-commercial. A full data refresh at most once a week, cached locally, at a low request rate.
Only I see the data, in my own planner.
